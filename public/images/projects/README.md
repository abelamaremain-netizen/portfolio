# Project Images

Place project screenshot images here.

Expected files:
- `legalcase.png` — screenshot for the LegalCase project card
- `cooperative.png` — screenshot for the Cooperative Management System card

Images should ideally be 16:9 ratio at ~800×450px or larger.
`next/image` will resize and convert them to WebP automatically.
If an image is missing, the card gracefully hides the broken `<img>` via the `onError` handler.
